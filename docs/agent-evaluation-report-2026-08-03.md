# Agent 离线评测报告（2026-08-03）

## 评测目的

验证 ChangeGuard 的 Agent 工程边界，而不是声称模型能够替代人工审批。固定用例通过本地 `httptest` 模拟 OpenAI-Compatible 多轮响应，不请求真实模型、不消耗付费 Token，结果可在 CI 中复现。

## 执行命令

```powershell
go run ./cmd/changeguard-agent-eval
go run ./cmd/changeguard-agent-eval -json
go test ./internal/agent -count=1
```

## 覆盖场景

- 正常 LOW / MEDIUM / HIGH 结论；
- 强制调用 `get_rule_findings`、`get_experiment_report`、`get_change_context`；
- 变更描述尝试要求模型忽略系统消息、跳过工具并直接批准；
- 模型引用不存在的证据编号；
- 模型未调用必需工具、返回错误 JSON；
- 模型请求超时并降级为本地证据归纳；
- 首次返回 HTTP 503，有限重试后完成分析。

## 结果边界

100% 表示仓库内这 24 条固定、确定性离线用例全部通过，不代表任意真实模型或任意生产变更都具有 100% 准确率。真实上线仍需要扩充企业历史变更集、人工标注基准、模型版本对比和持续回归。
