# ChangeGuard 产品范围

## 用途

ChangeGuard 用于管理生产发布前的 SQL、应用配置和 Kubernetes 变更。它运行确定性检查，记录人工审批，并签发与制品摘要绑定的一次性通行证。CI 在部署前重新计算工作区文件摘要并消费通行证，从而发现审批后替换文件、使用错误环境授权或重复发布等情况。

它适合已经使用 Git 和 CI/CD、但仍依赖聊天记录、表格或通用工单审批生产变更的团队。ChangeGuard 不要求替换现有代码托管、构建或部署工具。

## 要解决的问题

### 审批对象与部署对象不一致

只审批工单文字或截图，无法保证流水线最终使用同一份文件。ChangeGuard 对制品及参与摘要的元数据计算 SHA-256，审批和通行证都绑定该摘要。CI 必须从实际发布文件重算摘要。

### 重复人工检查

SQL 无条件更新、明文凭据、特权容器和 `latest` 镜像等问题适合用稳定规则先行检查。每个发现项包含规则编号、级别、位置、证据和整改建议；业务影响、发布窗口和例外理由仍由审核人判断。

### 审计事实分散

变更版本、检查结果、审批、通行证状态和 CI 消费事件记录在同一条时间线中。报告只陈述系统实际记录的事实，不把静态检查描述成运行验证，也不把通行证消费描述成部署成功。

## 使用者

| 角色 | 主要操作 |
| --- | --- |
| 开发者 | 创建和更新变更，处理规则发现项，提交审批 |
| 审核人 | 核对制品、检查结果、业务影响和回滚方案，批准或拒绝 |
| 负责人 | 管理组织、应用、成员、规则和授权 |
| CI/CD | 对实际文件计算摘要，验证并消费一次性通行证 |

提交人不能批准自己的变更。组织和应用权限在服务端校验，不能依赖前端隐藏操作。

## 支持的变更

### SQL

检查高风险 DDL/DML、缺少条件、回滚内容和执行约束。生产通行证要求迁移 SQL 与回滚 SQL 在隔离的 PostgreSQL 影子事务中完成验证；并发索引语句使用去掉 `CONCURRENTLY` 的事务内等价形式。该验证不等同于生产数据、锁竞争或性能验证。

### 配置

处理 YAML、JSON 和 ENV 风格配置，检查疑似明文敏感信息、不安全开关和过宽访问设置。配置检查是静态检查，不生成虚构的运行结果。

### Kubernetes

检查工作负载清单中的镜像标签、容器权限、主机挂载、资源限制和健康探针。ChangeGuard 不连接 Kubernetes API，也不执行部署。

## 主要流程

1. 开发者选择应用和环境，提交一个或多个制品及回滚方案。
2. 服务端对原始字节计算摘要，保存可审阅的安全表示并运行确定性规则。
3. SQL 在静态规则通过后进入隔离 PostgreSQL 影子验证；配置和 Kubernetes 直接进入待审批。
4. 独立审核人批准或拒绝当前版本。
5. 实际审批人签发一次性通行证；明文 Token 只显示一次。
6. CI 从实际发布文件重算摘要，先 `verify`，再在部署前 `consume`。
7. 消费成功后变更记为 `COMPLETED`。部署结果、事故和回滚结果由外部系统另行回传。

修改制品、环境、应用或参与摘要的关键元数据会使旧审批和未消费通行证失效。

## 通行证约束

- 绑定组织、变更、环境、规则版本、制品摘要和审批信息；
- 默认有效期 10 分钟，可配置为 1～30 分钟；
- 默认只能成功消费一次；
- 原始 Token 只在签发响应返回，持久化层只保存摘要；
- 过期、吊销、重复消费、摘要不一致或环境不一致均失败；
- Gate 不可用或返回不明确结果时，流水线必须停止。

## 审计与证据

ChangeGuard 记录变更、检查、发现项、审批和通行证事件。证据包排除制品正文、明文 Token 和 Token 摘要，自由文本经过统一脱敏。审计哈希链提供应用级篡改检测，但不是 WORM、第三方时间戳或不可抵赖证明。

## 非目标

ChangeGuard 不负责：

- Git 托管、构建、发布编排或集群操作；
- 在生产数据库执行 SQL；
- 预测生产锁等待、P99 或业务正确性；
- 让模型或概率评分自动决定放行；
- 替代 ITSM、CMDB、GRC、SIEM 或可观测平台；
- 保存生产密钥或将变更制品作为密钥仓库；
- 保证通行证消费后的部署成功或服务健康。

## 验证要求

涉及权限、组织隔离、状态迁移、幂等、持久化恢复和失败关闭的行为需要自动化测试。SQL 运行证据必须来自真实隔离 PostgreSQL；未运行的场景明确标记为 `NOT_RUN` 或 `DEMO_ONLY`。性能结果只应引用仓库中可重复运行的 benchmark，并注明测量环境与限制。
