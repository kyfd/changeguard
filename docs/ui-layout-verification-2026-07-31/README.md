## 本轮最终结论

- 日常工作台已学习授权参考系统的浅色企业后台语言：浅灰画布、白色侧栏与卡片、蓝色主色、细边框、分离式指标卡；未复制企业 Logo、IP、专有图标或真实资产数据。
- 新增独立的“生产变更治理全景”：中央拓扑展示业务应用、数据库、Kubernetes、配置、CI/CD 和规则策略，左右展示风险、排行、薄弱控制与治理闭环。
- 全景数字来自当前登录企业的应用、变更、规则、证据、审批和通行证状态，不是写死的展示数字。
- 字体实测：正文/表格/详情值 14px，详情标签 13px，徽标与代码最小 12px，导航与按钮 14px，卡片标题 16px。
- 修复详情页返回按钮 SVG 默认尺寸导致文字竖排、全景侧栏内容裁切、旋转背景造成隐藏横向滚动，以及表格 `<small>` 继承为 11.67px 等问题。

## 修复结论

- 变更表中的风险、状态、证据、通行证和类型徽标保持单行，不再出现“待评估”逐字竖排。
- 文本型风险值使用可扩展标签；数值或单字风险仍保留紧凑方形视觉。
- 宽内容区使用完整表格；实际列表容器不足 `820px` 时直接切换为带边框的响应式卡片，不再依赖视口宽度硬挤列。
- 卡片完整保留类型、状态、风险等级、证据状态、目标服务、环境、申请人与更新时间。
- 风控规则代码、名称、说明、风险、处置状态和开关不再重叠。
- 规则列表使用容器查询：内容区域不足 `780px` 时自动切换为堆叠卡片，而不是继续压缩列。
- 长规则代码在桌面端安全省略并保留完整 `title`，卡片端允许自然换行。
