# 2026-09-28 收尾记录

基线：`2ee003a`（v3.0.9）。本轮仅修改本地代码，未部署生产、未运行付费模型请求。

## 修复范围

- Go 实际模型分析与连接探测共用安全 HTTP 客户端：禁止跟随重定向，在建立连接时解析并校验全部 IP，直接连接已校验 IP，避免再次 DNS 解析造成重绑定。HTTPS 仍按原始域名验证证书。
- 默认拒绝内网、环回及链路本地地址；`DBGUARD_MODEL_ALLOW_PRIVATE_UPSTREAM=true` 仅为明确的内网部署放行环回/私网，仍拒绝链路本地地址。
- “获取模型列表”只绑定一次，不随快捷预设数量重复或缺失；请求进行中禁用按钮；Anthropic 不发送不支持的列表请求。
- 保存提示使用后端真实返回的 `enabled`、`has_api_key`、`provider`，不再依赖不存在的 `configured` 字段。
- 配置页面明确：企业 Key 仅供 Go 变更辅助分析，Python `/agent/` 仍独立配置 `AGENT_LLM_*`；Anthropic 目前只支持保存及连接测试。

## 部署兼容性

安全客户端不使用 `HTTP_PROXY` / `HTTPS_PROXY` 环境代理，防止代理路径绕过目标 IP 校验。依赖代理才能访问模型的环境需要提前评估，不能直接升级后假设仍可连通。

本轮 Go 及嵌入式页面需重新构建核心二进制。未改变 Python Agent、数据库或 API 数据结构。

完整上线仍需分别核对 Go release、Python Agent commit、Compose 配置；核心发布包不包含 Python Agent。升级前备份配置、主库和 Agent 持久化目录；验证健康、登录、任务创建、材料确认及恢复链路。失败时恢复原核心版本，注意旧版本会恢复原出站安全风险。
