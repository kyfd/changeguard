浏览器与 CLI 全流程使用两个独立后端容器、共享真实 PostgreSQL/Redis、专用 SQL 影子库：创建配置与 SQL → 静态检查 → 迁移/回滚 → 禁止自审 → 独立审批 → 签发 → 篡改/错误环境拒绝 → 主实例消费后代理丢响应 → 第二实例同 consumer 重试 → 异 consumer 拒绝 → 状态、首次快照与单条审计核对。

首次 E2E 启动因缺少匹配的 Chromium 失败；安装项目锁定的浏览器后运行通过。截图检查另外发现内嵌详情将零发现项误判为未检查、字符串规则版本被转数字，以及请求不存在的影响图谱接口；修正后由 E2E 增加页面断言验证。

GitHub 提示旧 Playwright 1.55.0 存在浏览器下载证书校验告警。开发依赖升级为 1.55.1，`npm audit --registry=https://registry.npmjs.org --json` 返回 0 项已知漏洞；这不等于全项目安全审计。补丁版本需要重新安装其匹配的 Chromium。
